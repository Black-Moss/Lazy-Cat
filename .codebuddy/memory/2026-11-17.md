# 2026-11-17

## 模型 datagen Builder（参照配方 Builder 形式）

- 完善空壳：`ModelContext` 增加 `itemModels()` / `blockModels()` getter，`AbstractModelBuilder` 增加 `context()` 与泛型 `self()`。
- 新增通用 Builder（`api/model/`）：`ItemModelBuilder`（默认按物品 id 生成 `FLAT_ITEM`）、`BlockModelBuilder`（`cubeAll` 默认、`custom(MultiVariant)`、`facing()`、`onlyState()`、`onlyItem()`）。
- 新增 Avaritia 8 种模型 Builder（`model/avaritia/`）：5 个纯效果（Cosmic / CosmicArc / Hell / Eternal / Unstable，共享 `AbstractEffectModelBuilder` + `BiFunction` 工厂）+ 3 个光环（Halo / HaloCosmic / HaloEternal）；`api/model/avaritia/AbstractAvaritiaModelBuilder` 提供 model/mask/tint/texture/color/size/pulse 与统一 save；`AvaritiaModelBuilder` 由反例静态方法改为返回 8 种 Builder 的门面。
- 关键签名：`MultiVariant` 在 `net.minecraft.client.data.models`（不是 `renderer.block.dispatch`）；模型入口是 `ModelProvider.registerModels(BlockModelGenerators, ItemModelGenerators)`；Avaritia 反编译源码里 Halo 的 color 传的是负值，Builder 内用 `-color`。
- 实跑验证：临时 Provider 覆写 `getKnownItems/getKnownBlocks/registerModels` 跑 `gradlew runData`，生成 JSON 正确（`avaritia:halo` 的 color=-16724838 / texture=avaritia:misc/halo / size=8、扁平物品、方块 state 与 cube_all）。注意：覆写 `registerModels` 时不要调用 `super.registerModels(...)`，否则 known 方块的默认模型会与 Builder 输出重复。验证后已清理临时 Provider、还原 `LazyCat.java`、删除 generated 产物，`compileJava` 通过。
- 新增 `example/ExampleModelProvider.java`：全注释参考示例（与 `ExampleResearchProvider` 同风格），覆盖通用 Item/Block Builder、Avaritia 8 种 Builder、`getKnownItems/getKnownBlocks` 同步要求、以及 `GatherDataEvent.Client` 注册片段。
